# Power BI Data Modeling Project
---

## 📖 **Overview**
---

This project focuses on data modeling in Power BI, with less emphasis on dashboard design and visual presentation.
The main goal was to build a structured data model using multiple fact and dimension tables, establish appropriate relationships, and prepare the model for further analysis and reporting.

## 📊 **Data Modeling**
---

The project uses a Galaxy Schema.
The model includes:
- multiple fact tables
- shared dimension tables
- one-to-many relationships
- surrogate keys
- date dimensions
- separate measures table

The main focus was on creating a clear and consistent model that can support analysis across different business areas.

## 🎯 **Key Skills**
---
- designing analytical data models
- fact and dimension tables
- relationship management
- data transformation with Power Query

## 📚 **About the Project** 
---
This project was created as part of a Power BI Data Modeling course by **Data with Baraa** and was used as a hands-on exercise to develop my skills in data modeling and Power Query.
